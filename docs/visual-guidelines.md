# Diretrizes Visuais — CyberTech

Fonte de verdade para aparência. Derivado de `.agents/memory/visual-direction.md`.

## Paleta
- Azul claro como cor predominante.
- Azul-escuro apenas em faixas horizontais, menu e rodapé.
- Fundo geral claro; evitar fundo escuro em toda a página.

## Movimento
- Hover effects e entradas com pequenos delays no scroll.
- Movimentos discretos, sem bloquear navegação.
- Respeitar `prefers-reduced-motion`.

## Componentes
- Usar shadcn/ui (Radix) como base; customizar via Tailwind.
- Ícones: lucide-react (e react-icons quando necessário).

## Tipografia
- Fontes do sistema/Tailwind default; hierarquia clara.

## Responsividade
- Mobile-first; breakpoints padrão Tailwind.
